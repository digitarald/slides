Elicitations

Servers that talk back

Elicitations let a server communicate with the user directly — bypassing the agent — so sensitive decisions and credentials never pass through the model.

Four use cases

  • Configuration — "Which environment? Staging or prod?"
  • Confirmation — "This will delete 3 tables. Proceed?"
  • Selection — "Pick a service boundary from this list"
  • Secure auth handoff — URL elicitation redirects to OAuth/SSO

Two flavors, different trust models

  • Form elicitations — in-band: structured input rendered in the client UI
  • URL elicitations — out-of-band: redirect to external flows; credentials never touch the client or the agent
