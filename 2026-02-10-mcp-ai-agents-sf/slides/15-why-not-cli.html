The Skeptic's Question

"You can do everything
with bash."

That's true for execution. But you've now seen what MCP adds beyond CLI tools:

💬

Elicitations

Server-to-user input that bypasses the model. Bash can prompt — but it can't redirect to an OAuth flow, receive a scoped token, or decide what the agent shouldn't see.

⏳

Tasks

Progressive updates in the agent UI. Bash has stdout — but the agent doesn't surface "3 of 12" in a structured progress bar. Long work is a spinner or silence.

🖥️

MCP Apps

Interactive UI inside the agent. Bash can't render a flame graph you can click on, or a checkout flow you can fill out, in the chat window.

Plus: agent identity

OAuth 2.1 with per-server audience binding (RFC 8707). Each MCP server gets its own scoped token. A compromised token for GitHub can't be replayed against your finance server. The GitHub MCP Server adds implementation-level OAuth scope filtering — detecting token type and hiding tools you lack permissions for.

"Bash does execution. MCP does collaboration."
