Platform

Making it scale

Too many tools confuse the model and bloat context. GitHub MCP Server's Projects toolset consumed ~23K tokens — consolidated by 50%.

Virtual Tools

When tools exceed a threshold, VS Code groups them automatically. The model activates groups on demand — hundreds of tools never hit context at once.

Tool Search

A meta-tool that helps Claude discover the most relevant tools from a larger pool — smart routing, not brute-force listing.

Smart Responses

Large tool responses are automatically summarized or chunked before hitting context — the model sees what matters, not a 50K-token dump.

🧩 MCP in Extensions

Extensions bundle MCP servers — zero config, auto-discovery, settings sync. Azure and GitHub ship built-in. Search @mcp in the marketplace.

📦 MCP Registry

Built-in discovery and install — browse verified servers from the MCP Registry directly in VS Code. One-click add to workspace.

🛠️ MCP Dev Mode

Add a dev key to your server config — file-watch restart, integrated debugger (Node.js + Python), and protocol-level logs. Most agent bugs aren't model bugs — they're server bugs. Dev mode makes behavior observable.
