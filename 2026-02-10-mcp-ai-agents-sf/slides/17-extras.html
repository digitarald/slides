Building Blocks

Four primitives
worth knowing

🧠 Sampling

Servers borrow the client's LLM via sampling/createMessage. No API keys needed — the server orchestrates, the client's LLM reasons, the user stays in control.

📋 Instructions

Server returns an instructions string at init — a "user manual for LLMs" injected into the system prompt. The difference between tools that work and tools that work well.

📂 Roots

Clients expose workspace roots — directories and files the server can operate on. Scopes what the server sees, enforces least-privilege.

🔄 Dynamic Tool Discovery

Servers add, remove, or update tools at runtime via notifications/tools/list_changed — the client picks up changes without restart.
