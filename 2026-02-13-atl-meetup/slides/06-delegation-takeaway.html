Delegation practices

End-of-day pattern

Hand off bugs to cloud agents in the evening, wake up to first-draft PRs. Take the bugs you meant to work on tomorrow and have the agent do a first pass tonight.

Automatic review

Cloud PRs get Copilot code review before you look at them. Six months ago the comments were too noisy. Now they're required before human review.

Issue triage at scale

VS Code replaced a rotating human "inbox tracker" with an agent — detects duplicates, assigns owners, suggests labels. Hundreds of issues a day, handled.
