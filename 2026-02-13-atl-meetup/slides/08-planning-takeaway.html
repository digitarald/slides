Planning practices

Trust ladder

Default → bypass → autopilot. Each level earns more autonomy. Autopilot isn't yolo mode — the agent has success criteria and loops until they're met.

"The spec is the prototype"

VS Code's PM Lead now prototypes in agent mode, self-hosts builds, and sends PRs to engineers. If the PM lead is shipping PRs, the capability bar has shifted for everyone.

Plans become artifacts

Write specs, discuss them with the agent, put plans into issues and PRs so they get tracked over time. Planning is the default workflow — not a special mode.
