ACT I — ELICITATIONS

The missing middle for input

Today it's "type more text." Elicitations give servers structured ways to ask—forms, selections, auth redirects—without the model mediating.

Form elicitation (in-band)

Structured input rendered inline

Text fields, select dropdowns, booleans

JSON Schema validated

Server defines schema, client renders the form

Agent never sees raw input

Server asks, user answers, model stays out

URL elicitation (out-of-band)

Redirects to external flow

OAuth, SSO, payment, MFA

Credentials never touch the client

Token exchange happens server-side

HTTPS-only, SSRF-safe

Client validates URL before opening
