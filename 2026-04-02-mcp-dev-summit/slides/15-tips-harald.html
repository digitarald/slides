BUILD FOR THE MISSING MIDDLE

Spec & design tips

Harald

TIP 01

Annotate your tools

readOnlyHint, destructiveHint, idempotentHint, openWorldHint. Annotating read-only tools instantly improves UX.

TIP 02

Use server instructions

instructions in InitializeResult is a "user manual for LLMs." Tell the model how to use your tools, not just what they are.

TIP 03

Resources for progressive disclosure

Use resources and linked resources—let the agent pull what it needs, when it needs it.
