TIP 01

MCP dev mode

Protocol logs, file-watch restart, debugger attach. Most agent bugs are server bugs—make behavior observable.

TIP 02

Enable tools dynamically

Don't show tools the user can't use. Token scope determines visibility.

if (scope.includes('repo')) enableTool('create_pr');

TIP 03

Use roots for scoping

Declare file:// URIs as boundaries. A server pointed at /repos/backend shouldn't index your docs folder.
